# التحقق — 2026-11-16

هذه نتائج نسخة محلية مع بيانات مصطنعة. لا تمثل اختبار حساب مدير المركز أو قاعدة بياناته الفعلية، ولا إرسال رسالة إلى جوال فعلي.

## نتائج آلية

`npm test`: نجحت الاختبارات الـ١٥، وتشمل:

1. رفض القراءة الإدارية دون دخول، وعدم عرض قائمة الطلاب أو أرقامهم في صفحة QR العامة.
2. التحقق من CSRF ومصدر الطلب.
3. قراءة التعديل في جدول الدورات نفسه، وحفظ الطالب والتسجيل في جداول الموقع المشتركة، مع دعم رقم جوال بالأرقام العربية.
4. إنشاء حصة واستبعاد الانتظار، ورفض المواعيد المتداخلة والقديمة.
5. رفض رمز طالب خاطئ، وثبات وقت الحضور عند تكرار الطلب.
6. منع الانصراف قبل تسجيل الحضور أو قبل نافذة الانصراف، وثبات وقته عند التكرار.
7. رفض الحضور المبكر جدًا والرمز المنتهي والحصة المغلقة.
8. عدم تجهيز تنبيه قبل ٢٠ دقيقة، وتجهيزه عند بلوغها، وعدم تكرار صف الرسالة.
9. استبعاد الحاضر وصاحب العذر وصاحب التسجيل الملغى.
10. إلغاء التنبيه الذي لم يرسل عند الحضور المتأخر.
11. عدم تسجيل الرسائل المعطلة كمرسلة أو محاولة الاتصال بمزوّد في التجربة.
12. انتهاء التنبيهات القديمة بنهاية الحصة وإغلاق الحصة.
13. عدم كشف تجزئة الرمز في API، وإبطال الرمز القديم بعد تجديده.
14. فحص حد ١٩:٥٩ / ٢٠:٠٠ بدقة، ونقل المجموعة، وتفسير قبول المزوّد ورفضه وانقطاعه واستجابته غير المؤكدة.
15. تنفيذ حذف الطالب بواسطة API النظام الأساسي على قاعدة اختبار، والتحقق من المفاتيح الخارجية وتنظيف سجلات الحضور المرتبطة.

اجتاز TypeScript والبناء الإنتاجي، وفحص صياغة ملفات PHP الخمسة. حزمة npm خالية من ثغرات معروفة وفق فحص npm عند التثبيت؛ ليست نتيجة تدقيق أمني مستقل.

## تجربة المتصفح

- تسجيل دخول مدير التجربة ورؤية البيانات الفعلية من قاعدة المعاينة.
- معاينة لوحة الإدارة على 1280px و390px، وشاشة الطالب على 320px؛ قياس شاشة الطالب أعطى `scrollWidth=320` مقابل عرض 320 دون تجاوز أفقي.
- إنشاء حصة باسم «حصة تجريبية · متابعة الحضور» لمجموعة من كتالوج المركز، وحفظ موعدها ورمزها.
- فتح سجل الحصة وقراءة أسماء الطلاب وأرقام تسجيلهم وأوقات حضورهم.
- فتح صفحة الطالب من رابط الحصة، وإدخال رقم التسجيل `١` ورمز التجربة. ظهر «تم تسجيل حضورك» وحالة «حضور متأخر» ووقت الحفظ، وحُفظ التغيير في قاعدة المعاينة.
- نجح عرض الخط العربي والشعار الأصلي وQR، والتخطيط المتجاوب على الهاتف. QR المحلي يفتح على الجهاز نفسه فقط.

## ما يحتاج تحققًا على الاستضافة

المسار الفعلي لملف SQLite وكود PHP وإصداره، وHTTPS للنطاق الفرعي، ووصول الهاتف إلى QR، وصلاحيات الملف، وتشغيل مهمة كل دقيقة حتى عند إغلاق اللوحة، وحساب SMS واسم المرسل ونتيجة رسالة اختبار معتمدة لدى المزوّد. هذه الخطوات لم تُنفذ بعد.
